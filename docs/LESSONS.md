# Lessons

One dated row per mistake already paid for. Read before every run.

| Date | Lesson | What happened |
|---|---|---|
| 2026-10-31 | Fetch Finnhub's earnings calendar **per day**; it silently caps at 1500 rows per request. | Nov 2–6 returned exactly 1500 rows and was missing companies. |
| 2026-10-31 | Never fire more than ~6 Finnhub calls at once (`pool()`); bursts get 429s and whole days vanish. | 25 parallel day fetches → 3 days missing from November. |
| 2026-10-31 | Finnhub free history only reaches back about a month, and `symbol=` returns future dates only. Past report dates come from Nasdaq. | Reaction history was empty until Nasdaq's earnings-surprise endpoint was used. |
| 2026-10-31 | Don't spread `res.headers` into a plain object and add `Content-Type` again; duplicate casing breaks HTMLRewriter ("Unknown character encoding"). Use `new Headers()` + `set`. | Every HTML page returned 502 after adding share meta. |
| 2026-10-31 | e2e fixtures are routed by the request's `to` date; a page that asks for a forward range needs the November fixture. | Compass showed no exposure in tests because it got October's (already reported) data. |
| 2026-10-31 | Metaphases lives at **mutaafaziz.com/metaphases/**, not its own domain (operator decision). Never write root-relative URLs (`/api/…`, `/compass`): use `BASE` and `href()` from `src/lib/router.ts`; the e2e suite checks nav and manifest hrefs. | The first build assumed a root domain, and every link and API call had to be re-based. |
| 2026-10-31 | In the worker, fetch the SPA shell as `${BASE}/`, never `/index.html`: the asset layer answers index.html with a 307, and rewriting a redirect gives an empty 200. Check pages with `curl` + byte count, not just status. | Every HTML route went blank on the first mutaafaziz.com deploy. |
| 2026-11-01 | In the cloud sandbox, Playwright 1.64's expected Chromium build isn't installed; don't `playwright install`. Run e2e with a throwaway config that sets `launchOptions.executablePath: "/opt/pw-browsers/chromium-1243/chrome-linux64/chrome"` (and don't commit it). | `npm run check` failed all 24 e2e tests with "Executable doesn't exist". |
| 2026-11-01 | When a dialog opens from a keystroke, move focus into it on the next frame, not synchronously. Chrome fires the Enter keypress at whatever is focused after keydown, so a synchronously focused close button gets "clicked". `useDialog` defers focus with requestAnimationFrame. | Enter in ⌘K search opened the ticker sheet and immediately closed it. |
| 2026-11-01 | Finnhub dates with a blank `hour` are often projections: AXON showed Nov 2 while the company announced Nov 5. Cross-check a few names against company press releases each run. | Scout spot-check found a wrong date live. |
| 2026-11-01 | A no-horizontal-scroll check on `document.documentElement` misses overflow inside scrollable dialogs. Measure `[role=dialog]` scrollWidth too. And when judging a beat or miss, check that estimate and actual share a basis and currency: Finnhub's GOOGL revenue actual is ex-TAC while the estimate is gross. | The phone ticker sheet was 534px wide in a 390px viewport with CI green; GOOGL showed a −15.8% revenue "miss" on an in-line quarter. |
| 2026-11-01 | In a CSS grid, `1fr` means `minmax(auto, 1fr)`: a child's min-content (nowrap labels, buttons) widens the track and every sibling with it. Use `minmax(0, 1fr)` (also for implicit single-column grids like `.sheet-body`) plus `min-width: 0`, and test at 360px, not just 390. | The ticker sheet was 534px wide at 390px because three `1fr` stat columns and nowrap trend labels set the grid's minimum. |
| 2026-11-01 | Layout assertions in e2e must not run mid-animation (emulate `reducedMotion: "reduce"`), and an "ignore anything inside an overflow:hidden ancestor" exemption hides exactly the clipped-text bug you're testing for: allowlist intentional clippers by selector and check text ranges. Draw decorative halos inside the box instead of `overflow:hidden` on a card that hosts glossary pops. | The first 0010 test flaked 1 in 12 on the sheet's slide-in, passed with stat values clipped inside the card, and the card clipped its own glossary pops. |
| 2026-11-01 | `/api/health` being `ok:true` doesn't mean the product works: it only probes upstreams. In preflight, also curl a few `/api/ticker/:sym` and `/t/:sym` cache-busted and count `503 error code: 1102` (Worker resource limit). | Health was green while ~30% of ticker and share requests failed with 1102. |
| 2026-11-01 | A blank-session Finnhub date can't be confirmed from one aggregator; WebSearch rarely finds the company release for mid-cap names. Scout tickets should detect disagreement between sources (Nasdaq) in code rather than rely on hand spot-checks. | CEG showed Nov 9 while another calendar listed Nov 6, with no company release found. |
| 2026-11-01 | Free Workers get about 10 ms of CPU per request. Never cache or parse a raw upstream payload you only use 5% of (Finnhub metric=all is 196 KB); slim it before caching, and cache the finished response. Health must probe the user path, not just the upstreams. | About 1 in 3 ticker and share requests returned Cloudflare 1102 while /api/health said ok. |
| 2026-11-01 | Finnhub calendar estimates for foreign filers are in the **reporting currency** (JPY, RMB, TWD, DKK), not USD, while Nasdaq history is USD. Never format a Finnhub estimate with `$` without knowing its currency, and never compare it with a Nasdaq figure. Critic: include one ADR (TM, PDD, NIO) in every numbers check. | Toyota showed "$64.50" EPS and "$13.48T" revenue; NIO's Read compared RMB with USD. |
| 2026-11-01 | Finnhub profile2 `currency` and `marketCapitalization` are **not** a reliable estimate basis: SQM's currency is CLP while it files in USD, and NIO's market cap is USD while its estimates are RMB. Use `estimateCurrency`, then the universe `ec` seed, then a USD-history ratio check (floor 0.20 so GAAP-vs-adjusted gaps like ESTC don't trip it). Universe `mc` for TM/SONY/HMC/TSM is also in local currency, so `popularity()` ranks Toyota above Nvidia: separate ticket. | 0021: TM showed "$64.50" EPS; the first ratio floor (0.05) labelled ESTC as euros. |
| 2026-11-01 | `curOf()` only knows the universe: untracked foreign reporters admitted to the calendar by revenue ≥ 1e9 (KSPI KZT, DIDIY CNY, TBBB MXN) still render with "$", and their local-currency revenue is what let them past the 1e9 gate. The fix belongs server-side (a per-event `cur` from `estimateCurrency()`), which needs its own ticket. Quarterly figures from Finnhub filings (`quarters[]`) share the estimate's currency, not Nasdaq's USD. | 0021 self-review: the sheet's quarterly trend said "Revenue ≈ $31.9B" for NIO (RMB) right under a note claiming past results were in dollars. |
| 2026-11-02 | A fix that passes its bar right after deploy can regress on the next deploy or a cold Monday. Critic: re-measure every shipped reliability ticket on **un-busted first calls across 150 names**, not 20 warm large caps. Also diff sheet `next.date` against the calendar per symbol: the sheet (`symbol=`) and the calendar (per-day) are separate Finnhub queries and can disagree on membership. | 0012 measured 0/60 at 18:58 and 57/150 at 07:00 the next day; TM/SONY/HMC had a Nov 5 sheet date but no calendar row. |
| 2026-11-02 | Never judge a revenue (or EPS) surprise without a sanity bound on the basis: a >12% revenue "surprise" is far more often net-vs-gross or currency than a real result (`shared/compare.ts`). And one quarter must have one consensus: the calendar (Finnhub) and the sheet history (Nasdaq `consensusForecast`) disagreed on META by $0.73; `pickConsensus` prefers Finnhub. | 0011: GOOGL showed a −15.8% revenue miss on an in-line quarter; META showed +28% in one place and +13.5% in another. |
| 2026-11-02 | Never call timezone-aware `toLocaleDateString`/Intl in a per-item loop on Workers: it's very slow and ~10k calls per sheet blew the 10 ms CPU budget. Yahoo daily bars are stamped at the 9:30 ET open, so the UTC date is the NY date (`nyDate` in shared/depth.ts; unit test pins it). Long calendar ranges load a week per request (src/lib/api.ts). | 0012 bounced: 57/150 cold sheet opens failed with 1102 after a cache-key bump forced cold builds in the busiest week. |
| 2026-11-02 | Finnhub's calendar `epsEstimate`/`revenueEstimate` for an **already-reported** quarter isn't the pre-report bar: it drifts toward the actual (V 3.5055 vs 3.48 actual vs 3.43 pre-report). Judge beats against a pre-report snapshot or Nasdaq's `consensusForecast`, and sanity-check any season beat rate against history (~75% EPS, ~65% revenue). Also, Cloudflare injects a Web Analytics beacon at the edge that's invisible in the repo and to plain `curl`: check HTML with a browser UA and `Accept: text/html`. | Critic 19:00: 11 of the 60 largest reporters flipped verdict (9 beats shown as misses), the S&P revenue beat rate read 41%, and `static.cloudflareinsights.com` loaded on /kids. |
| 2026-11-03 | Diff the whole tracked universe against Nasdaq's per-day calendar (`api.nasdaq.com/api/calendar/earnings?date=`), not 8 hand picks; it finds conflicts in seconds. And check names whose Finnhub date already **passed without an actual**: the sheet's `next` silently skips to the following quarter. | Critic 07:00: Nasdaq matched the company release 5/5 where Finnhub missed 5/5 (FIS, APD, STE, ARM, AXON), and AXON's Nov 5 report showed as "Feb 22". |
| 2026-11-03 | A batched upstream call needs two different fallbacks: **truncated** (split it, through `pool()`) and **failed** (go to the stale copy). Never answer a failed or 429'd call by fanning out into more calls; that turns one rate limit into a retry storm for every visitor on the same key. | #43 self-review: a failed week range fired 5 unthrottled per-day retries, and a truncated busy week burst 15 day calls at once. |
| 2026-11-03 | On a report day, diff each same-day reporter's sheet (`/api/ticker` `next`, The Read, og tags) against the calendar's actual. The sheet's `next` ignores `epsActual` and history comes from Nasdaq a day late, so morning and early-afternoon runs see "expects" on reports that are already out. Morning runs miss it entirely. | Critic 19:00: 79/81 before-open reporters had calendar actuals while every sheet still said "Before open · today · EPS EST". |
| 2026-11-03 | Company-announced dates live in `data/date-overrides.json` (quarter/year = Finnhub's labels, https `source`, `checked` ≤ 30 days while active; `npm test` enforces it). Add an entry when a company release disagrees with Finnhub; delete entries 14 days after their date. Also: `kids-followups.spec.ts:95` (Move my progress) is order-flaky on main when run with other specs; it passes alone and CI retries once. | 0013: ARM, FIS, STE, APD and AXON all showed Finnhub's projection over the company's own release. |
| 2026-11-04 | A failed request is unknown, not empty: a 503'd calendar range must never render as "No earnings", "· 0", "A quiet stretch" or a low season %, and a 503'd ticker must never read as "double-check the ticker". Thread the HTTP `status` through `useApi` (404 = not found, anything else = busy) and use `missingDays()` (src/lib/partial.ts) to mark failed days. Also: `kids-followups.spec.ts:95` fails locally even alone because a late `kids-icon.svg` request lands in its "sends nothing" list. | 0026: Hype Check called Axon a possible penny stock during a 1102 episode; the season strip read 32% then 57%; failed days on the grid said "No earnings". |
| 2026-11-04 | A past-dated calendar row with no actual is one of two different things: **not reported yet** (Nasdaq per-day calendar has a future date: WES, PAA) or **reported, but the feed has no figures** (Nasdaq `earnings-surprise` latest `dateReported` matches or `dateReported` is newer: ROKU, BC). Classify it before you file or fix it. In peak week the count tripled (6 → 17) in 12 hours. Also, Playwright scripts that dismiss the lens picker must click the option text ("I invest for the long run"): a role/name match hits the hidden Trader toggle behind the scrim and times out. | Critic 07:00: 0013 fixed 5 names while orphans grew from 6 to 17. ADM (reported) and WES (due tonight) both showed "next report: February". |
| 2026-11-04 | When the sandbox can't open a company release (GlobeNewswire answers 403 and bot-checks are off limits), confirm the override against Nasdaq's per-day calendar (`api.nasdaq.com/api/calendar/earnings?date=`, an allowed host) before committing it, and say so in the entry's `note`. | 0013 bounce: PAA's GlobeNewswire release was unreadable from the sandbox, but Nasdaq showed PAA pre-market on Nov 6 and WES after hours on Nov 4, matching both releases. |
| 2026-11-04 | Finnhub's day/range calendar omits some tracked foreign filers (TM, SONY, HMC, NVO, SQM) that `symbol=` lists; the universe logo file name (`7203.T.png`) is Finnhub's home listing. The calendar now merges a cached per-symbol supplement (`shared/calendarSupplement.ts`, ≤ 4 calls per request, none after a failed range). Unit tests that count upstream calls must count range calls (`symbol=` excluded). Surfacing foreign names exposes local-currency `mc` (0042): check the brief's top reporter whenever a big foreign name is added to a fixture. | 0024: 5 of 19 sheet dates in the next 30 days had no calendar row; adding TM to a fixture made Toyota the week's "biggest" reporter. |
| 2026-11-04 | Sweep `/api/ticker` with a browser User-Agent (Python urllib gets Cloudflare 403s on every call) and at most 2 in flight: a 119-sheet sweep at 4 concurrent used up the Finnhub quota, and the degraded sheets it produced were edge-cached for 5 min (0043). Re-fetch any degraded sheet alone after 60 s before calling it a product defect. On phones, test deep links by *answering* the lens picker, not just by checking whether it covers the sheet: the Everyday choice redirects to /today and drops `?t=`. | Critic 19:00: a first sweep reported 119/119 "failed" (all 403), the second degraded UBER/SUN/ADNT for everyone, and `/t/WES` → "I invest for the long run" → /today. |
| 2026-11-04 | Never filter an upstream answer by a field you haven't seen in production. Finnhub's `symbol=TM` answer doesn't come back labelled `TM` (most likely the home listing `7203.T`), so a strict `e.symbol === sym` guard dropped every ADR row. And when a cached document can hold a bad result, bump its key with the fix. Also, `npm run check:fast | grep` hides a test file that fails to parse: read the `Test Files` line. | #54 deployed with the supplement filling in (60 → 44 unchecked) while TM, SONY, HMC, NVO and SQM stayed off the calendar. |
| 2026-11-05 | Mount `useDialog` only in a component that renders the dialog: its effect runs once (`[]` deps), so a component that returns `null` after the dialog closes keeps the Esc/Tab listener alive forever. Two dialogs both listening on `document` capture also both see one Esc, and `stopPropagation` does not stop a listener on the same node. `useDialog` now keeps a stack (only the active dialog acts, `top` for the lens picker) and uses `stopImmediatePropagation`. | 0025: Esc on the lens picker also closed the ticker sheet under it, and the old picker's Esc handler outlived the picker. |
| 2026-11-05 | Nasdaq is not ground truth either: once a company publishes its own notice, Nasdaq can still be wrong (CSCO Nov 11 vs Cisco Nov 12; HMC Nov 6 vs Honda Nov 10), so a Finnhub-vs-Nasdaq agreement check can miss real errors. Search the company notice ("schedules conference call") for the large names in the next 14 days. And run contrast scans only with no `[role=dialog]` open: a lingering scrim makes every nav label read 1.11:1. | Critic 07:00: 3 of 10 company-checked dates were wrong while both feeds disagreed with the company; the first contrast scan flagged 21 phantom failures. |
| 2026-11-05 | The repo pins a newer Playwright (headless shell 1248) than the sandbox ships (1243), so local e2e fails to launch with "Executable doesn't exist". `ln -sfn /opt/pw-browsers/chromium_headless_shell-1243 /opt/pw-browsers/chromium_headless_shell-1248` lets `npm run check` run in full (sandbox only, never commit it). Also, a new company override can move a symbol out of a week that an older test fixture expected it in (HMC in calendarSupplement): assert the new date, don't drop the check. | 0045: 236 e2e "failures" were all launch errors; the HMC override broke a 0024 supplement assertion. |
| 2026-11-05 | A progress note is not a failure: anything in a response's `warnings` makes the client show "the market data service is busy" and refetch the range twice (`src/lib/api.ts`), so a permanent "still checking" note tripled calendar traffic and showed a false failure on every load (0047). Check share-class scale too: Finnhub gives BRK.B per-Class-A EPS (1,500× the B share; Berkshire's 8-K prints both). And EDGAR `data.sec.gov/submissions/CIK….json` (generic UA) is the fastest way to check whether a company has filed its quarter yet. | 0046, 0047 |
