# Lessons

One dated row per mistake already paid for. Read before every run.

| Date | Lesson | What happened |
|---|---|---|
| 2026-10-31 | Fetch Finnhub's earnings calendar **per day**; it silently caps at 1500 rows per request. | Nov 2–6 returned exactly 1500 rows and was missing companies. |
| 2026-10-31 | Never fire more than ~6 Finnhub calls at once (`pool()`); bursts get 429s and whole days vanish. | 25 parallel day fetches → 3 days missing from November. |
| 2026-10-31 | Finnhub free history only reaches back about a month, and `symbol=` returns future dates only. Past report dates come from Nasdaq. | Reaction history was empty until Nasdaq's earnings-surprise endpoint was used. |
| 2026-10-31 | Don't spread `res.headers` into a plain object and add `Content-Type` again; duplicate casing breaks HTMLRewriter ("Unknown character encoding"). Use `new Headers()` + `set`. | Every HTML page returned 502 after adding share meta. |
| 2026-10-31 | e2e fixtures are routed by the request's `to` date; a page that asks for a forward range needs the November fixture. | Compass showed no exposure in tests because it got October's (already reported) data. |
| 2026-10-31 | Metaphases lives at **mutaafaziz.com/metaphases/**, not its own domain (operator decision). Never write root-relative URLs (`/api/…`, `/compass`): use `BASE` and `href()` from `src/lib/router.ts`; the e2e suite checks nav and manifest hrefs. | The first build assumed a root domain, and every link and API call had to be re-based. |
| 2026-10-31 | In the worker, fetch the SPA shell as `${BASE}/`, never `/index.html`: the asset layer answers index.html with a 307, and rewriting a redirect gives an empty 200. Check pages with `curl` + byte count, not just status. | Every HTML route went blank on the first mutaafaziz.com deploy. |
| 2026-11-01 | In the cloud sandbox, Playwright 1.64's expected Chromium build isn't installed; don't `playwright install`. Run e2e with a throwaway config that sets `launchOptions.executablePath: "/opt/pw-browsers/chromium-1243/chrome-linux64/chrome"` (and don't commit it). | `npm run check` failed all 24 e2e tests with "Executable doesn't exist". |
| 2026-11-01 | When a dialog opens from a keystroke, move focus into it on the next frame, not synchronously. Chrome fires the Enter keypress at whatever is focused after keydown, so a synchronously focused close button gets "clicked". `useDialog` defers focus with requestAnimationFrame. | Enter in ⌘K search opened the ticker sheet and immediately closed it. |
| 2026-11-01 | Finnhub dates with a blank `hour` are often projections: AXON showed Nov 2 while the company announced Nov 5. Cross-check a few names against company press releases each run. | Scout spot-check found a wrong date live. |
| 2026-11-01 | A no-horizontal-scroll check on `document.documentElement` misses overflow inside scrollable dialogs. Measure `[role=dialog]` scrollWidth too. And when judging a beat or miss, check that estimate and actual share a basis and currency: Finnhub's GOOGL revenue actual is ex-TAC while the estimate is gross. | The phone ticker sheet was 534px wide in a 390px viewport with CI green; GOOGL showed a −15.8% revenue "miss" on an in-line quarter. |
| 2026-11-01 | In a CSS grid, `1fr` means `minmax(auto, 1fr)`: a child's min-content (nowrap labels, buttons) widens the track and every sibling with it. Use `minmax(0, 1fr)` (also for implicit single-column grids like `.sheet-body`) plus `min-width: 0`, and test at 360px, not just 390. | The ticker sheet was 534px wide at 390px because three `1fr` stat columns and nowrap trend labels set the grid's minimum. |
| 2026-11-01 | Layout assertions in e2e must not run mid-animation (emulate `reducedMotion: "reduce"`), and an "ignore anything inside an overflow:hidden ancestor" exemption hides exactly the clipped-text bug you're testing for: allowlist intentional clippers by selector and check text ranges. Draw decorative halos inside the box instead of `overflow:hidden` on a card that hosts glossary pops. | The first 0010 test flaked 1 in 12 on the sheet's slide-in, passed with stat values clipped inside the card, and the card clipped its own glossary pops. |
| 2026-11-01 | `/api/health` being `ok:true` doesn't mean the product works: it only probes upstreams. In preflight, also curl a few `/api/ticker/:sym` and `/t/:sym` cache-busted and count `503 error code: 1102` (Worker resource limit). | Health was green while ~30% of ticker and share requests failed with 1102. |
| 2026-11-01 | A blank-session Finnhub date can't be confirmed from one aggregator; WebSearch rarely finds the company release for mid-cap names. Scout tickets should detect disagreement between sources (Nasdaq) in code rather than rely on hand spot-checks. | CEG showed Nov 9 while another calendar listed Nov 6, with no company release found. |
| 2026-11-01 | Free Workers get about 10 ms of CPU per request. Never cache or parse a raw upstream payload you only use 5% of (Finnhub metric=all is 196 KB); slim it before caching, and cache the finished response. Health must probe the user path, not just the upstreams. | About 1 in 3 ticker and share requests returned Cloudflare 1102 while /api/health said ok. |
| 2026-11-01 | Finnhub calendar estimates for foreign filers are in the **reporting currency** (JPY, RMB, TWD, DKK), not USD, while Nasdaq history is USD. Never format a Finnhub estimate with `$` without knowing its currency, and never compare it with a Nasdaq figure. Critic: include one ADR (TM, PDD, NIO) in every numbers check. | Toyota showed "$64.50" EPS and "$13.48T" revenue; NIO's Read compared RMB with USD. |
| 2026-11-01 | Finnhub profile2 `currency` and `marketCapitalization` are **not** a reliable estimate basis: SQM's currency is CLP while it files in USD, and NIO's market cap is USD while its estimates are RMB. Use `estimateCurrency`, then the universe `ec` seed, then a USD-history ratio check (floor 0.20 so GAAP-vs-adjusted gaps like ESTC don't trip it). Universe `mc` for TM/SONY/HMC/TSM is also in local currency, so `popularity()` ranks Toyota above Nvidia: separate ticket. | 0021: TM showed "$64.50" EPS; the first ratio floor (0.05) labelled ESTC as euros. |
